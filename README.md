# Merismos — Releases

Public installer downloads for [Merismos](https://github.com/mwangiiharun/merismos), an
airline "mother ticket" splitter. The source repository is private; this repo exists
only to host public download links for built installers.

See the [Releases](../../releases) page for the latest `.dmg` (macOS) and `.exe`/`.msi`
(Windows) installers.
